# Hardwood Broadcast assets

Tracked copies of the floor texture and UI fonts used by `/player`, `/lab`, and `/coach`. Player cutouts are not copied from the untracked concept set; they still come from `design/players/` and `/lab/credits`.

## Floor texture

- `floor.jpg` is derived from "Laminate Floor 02" by Poly Haven, https://polyhaven.com/a/laminate_floor_02 (source file: `laminate_floor_02_diff_2k.jpg` from dl.polyhaven.org). License: **CC0**.
- Derivation: tiled at 60%, warmed toward maple (R x1.12, B x0.82, saturation 0.9). A 32% dark overlay is applied in CSS (`--floor-dim`).

## Fonts (self-hosted in `web/fonts/hardwood/`)

- DSEG7 Classic Bold, DSEG14 Classic Bold — keshikan, https://github.com/keshikan/DSEG. SIL OFL 1.1.
- Bebas Neue — Dharma Type. SIL OFL 1.1 (via @fontsource).
- Inter 400/600/800 — Rasmus Andersson. SIL OFL 1.1 (via @fontsource).
- IBM Plex Sans Condensed 500/700 — IBM. SIL OFL 1.1 (via @fontsource).
- Kalam 700 — Indian Type Foundry. SIL OFL 1.1 (via @fontsource).
